# Calidad del agua en El Confital

Proyecto de investigación sobre la calidad del agua en El Confital, Las Palmas de Gran Canaria, utilizando parámetros químicos, indicadores de contaminación fecal, citometría de flujo y secuenciación del microbioma.

Realizado en colaboración con el Grupo de Oceanografía Biológica y Algología Aplicada, Universidad de Las Palmas de Gran Canaria.

Para una versión histórica del proyecto visita el [antiguo repositorio](https://codeberg.org/veraglg/bahiaconfital-old).
