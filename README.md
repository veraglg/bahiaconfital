# Contaminación fecal en la Bahía del Confital

Proyecto de investigación sobre la contaminación fecal en la Bahía del Confital (Gran Canaria, España) utilizando parámetros de calidad del agua, indicadores convencionales de contaminación fecal y composición del microbioma.

Realizado en colaboración con [Instituto de Oceanografía y Cambio Global](https://www.gob-iocag.ulpgc.es/) (IOCAG).

Para una versión histórica del proyecto visita el [antiguo repositorio](https://codeberg.org/veraglg/bahiaconfital-old).
