# Calidad del agua en la Bahía del Confital

Proyecto de investigación sobre la calidad del agua en la Bahía del Confital (Gran Canaria, España) utilizando parámetros químicos, indicadores de contaminación fecal, citometría y secuenciación del microbioma.

Realizado en colaboración con [Instituto de Oceanografía y Cambio Global, IOCAG-ULPGC](https://www.gob-iocag.ulpgc.es/).

Para una versión histórica del proyecto visita el [antiguo repositorio](https://codeberg.org/veraglg/bahiaconfital-old).
